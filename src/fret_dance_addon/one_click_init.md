# 一键初始化功能说明

`one_click_init.py` 实现的「一键初始化」用于简化角色初始化过程：不再需要手动在指板上摆放 `Fret_P0~P3` 指板记录器，也不需要从零开始摆右手三个状态，只需把 **6 个吉他定位点**摆到琴上，即可一键完成全部初始化（指板记录器 + 右手 Low/End/High 记录器自动落位）。

6 个定位点为：

| 物体名 | 含义 |
| --- | --- |
| `S1_F0` / `S1_F12` | 1弦的 0品（弦枕）、12品品格丝位置 |
| `S6_F0` / `S6_F12` | 6弦的 0品、12品位置（贝斯为 `S4_F0` / `S4_F12`） |
| `S1_Right` / `S6_Right` | 1弦、6弦上**右手放置的基准位置**（约拨弦处，吉他约音孔上方；贝斯为 `S4_Right`） |

中间弦的位置、右手各手指的触弦点、手掌/手臂/拇指轴心等其余物体位置均由这 6 个点计算得到。

## 使用流程

1. 在 FretDance 面板「初始化」区域选择乐器类型（指弹吉他/电吉他/贝斯）
2. 点击 **创建吉他定位点**：在 `GuitarPoints` 集合中按当前乐器类型生成 6 个空物体——`S1_F0`、`S1_F12`、`S6_F0`、`S6_F12`、`S1_Right`、`S6_Right`（贝斯为 `S4_*`；已存在则复用）
3. 将 6 个定位点移动（或吸附）到吉他的实际位置：
   - `S{n}_F0`：第 n 弦的 **0品（弦枕）** 位置
   - `S{n}_F12`：第 n 弦的 **12品品格丝** 位置
   - `S{n}_Right`：第 n 弦上 **右手放置的基准位置**（约拨弦处，指弹吉他通常在音孔上方）
   - `S1` 是 **1弦（最高音、最细的弦）**，`S6` 是 6弦（最低音，贝斯为 `S4`）
4. 点击 **一键初始化**：创建全部控制器与记录器，并根据定位点自动计算摆放 `Fret_P0~P3`，同时把右手 Low/End/High 三个状态的记录器摆到吉他上的期望位置
5. 如使用 MMD 模型：选中骨架，点击「初始化 mmd 骨骼」自动绑定手指（此步骤为独立按钮，不属于一键初始化）
6. **再次点击「一键初始化」**：此时手指控制器已被绑定到骨骼位置，勾选「记录基准状态」（默认勾选）即可把当前控制器姿态写入全部左右手基准状态记录器
7. 之后照常：为各状态摆姿势 → Set 精修 → 导出人物信息

## 定位点布局示意

```
        弦枕(0品)                    12品品格丝                      右手基准位置
 1弦  S1_F0 ●━━━━━━━━━━━━━━━━━━━━━━━━━● S1_F12 ━━━━ S1_Right ━━━→   → Fret_P0(1弦1品) / Fret_P2(1弦12品)
  ⋮         ⋮                           ⋮              ⋮
 6弦  S6_F0 ●━━━━━━━━━━━━━━━━━━━━━━━━━● S6_F12 ━━━━ S6_Right ━━━→   → Fret_P1(6弦1品) / Fret_P3(6弦12品)
             ↑                                          ↑
             Fret_P0/Fret_P1 由 0品点与12品点              中间弦的右手基准点由 S1_Right 与
             连线上按 12 平均律计算出，落在 1品品格丝处      S6_Right 沿弦方向线性插值得到
```

新建定位点的默认布局：1弦在 +X 侧，1弦与最低弦相距 5cm（吉他）/ 3cm（贝斯），0品到12品两排相距 30cm，右手定位点默认在 0品~12品距离的 1.25 倍处（约音孔上方），仅为了摆放前直观可见，实际位置由用户移动决定。

## 实现原理

### 1. Fret_P0~P3 在动画管线中的角色

动画生成端（`../animate/animate.py` 的 `twiceLerpFingers`）将 `Fret_P0~P3` 作为双线性插值的四个锚点，导出的 JSON 中对应 `LEFT_FINGER_POSITIONS` 的 `P0~P3`：

- **品方向插值**：`p_fret_0 = lerp_by_fret(fret, P0, P2)`，`p_fret_1 = lerp_by_fret(fret, P1, P3)`
- **弦方向插值**：`p_final = p_fret_0 + (p_fret_1 - p_fret_0) * stringIndex / max_string_index`

因此四个记录器的几何含义是固定的：

| 记录器 | 几何含义 |
| --- | --- |
| `Fret_P0` | **1弦 1品** |
| `Fret_P1` | **最低弦 1品**（吉他为6弦，贝斯为4弦） |
| `Fret_P2` | **1弦 12品** |
| `Fret_P3` | **最低弦 12品** |

指板记录器只有 `Fret_P0~P3` 四个：历史上的 `Fret_P4` 已移除（动画生成不使用），运行一键初始化时会自动删除场景中残留的 `Fret_P4` 物体。

一键初始化要做的，就是从定位点推出这四个位置。

### 2. 12平均律品格位置推导

设有效弦长为 L（弦枕到琴桥的距离）。12 平均律下，弦枕到第 n 品品格丝的距离为：

```
d(n) = L * (1 - 2^(-n/12))
```

- n = 12 时，d(12) = L/2，即 **12品恰好在弦长中点**。因此由用户提供的同弦两点可得弦长：

```
L = 2 * |F12 - F0|
```

- n = 1 时：

```
d(1) = L * (1 - 2^(-1/12))
     = 2 * |F12 - F0| * (1 - 2^(-1/12))
     = |F12 - F0| * 2 * (1 - 2^(-1/12))
```

即 **1品位置可由 0品、12品两点直接线性表示**：

```
F1 = F0 + (F12 - F0) * 2 * (1 - 2^(-1/12))
            ≈ F0 + (F12 - F0) * 0.112251375
```

代码中该系数为常量 `FRET_1_RATIO`。

于是：

```
Fret_P0 = S1_F0  + (S1_F12  - S1_F0)  * FRET_1_RATIO   # 1弦1品
Fret_P1 = Slow_F0 + (Slow_F12 - Slow_F0) * FRET_1_RATIO # 最低弦1品
Fret_P2 = S1_F12                                       # 1弦12品，直接取定位点
Fret_P3 = Slow_F12                                    # 最低弦12品，直接取定位点
```

### 3. 与 `lerp_by_fret` 锚点定义的一致性

`lerp_by_fret(fret, value_1, value_12)` 把 `value_1`、`value_12` 当作 1品、12品锚点，插值参数为：

```
t = (2^(-fret/12) - 2^(-1/12)) / (0.5 - 2^(-1/12))
```

即按「剩余弦长比率」线性插值。由于一键初始化把 `Fret_P0`/`Fret_P1` 精确放在 1品品格丝、`Fret_P2`/`Fret_P3` 精确放在 12品品格丝，动画端对任意品 `fret` 计算出的位置都会落在正确的品格丝位置上（fret < 1 时向弦枕方向外推，fret > 12 时向琴桥方向外推，同样符合几何）。

### 4. 读取世界坐标

定位点位置通过 `obj.matrix_world.translation` 读取，而不是 `obj.location`。这样即使用户把定位点 **parenting 到吉他模型**（移动吉他时定位点跟随），读取到的仍是世界坐标，摆放结果不会出错。

写入 `Fret_P0~P3` 前会先解锁其 `lock_location`，避免记录器被锁定时赋值失败。

### 5. 乐器适配

- 吉他（指弹/电吉他）：6 根弦，最低弦定位点为 `S6_F0`、`S6_F12`、`S6_Right`
- 贝斯：4 根弦，最低弦定位点为 `S4_F0`、`S4_F12`、`S4_Right`
- 「创建吉他定位点」按面板当前选择的乐器类型创建对应的 6 个定位点（切换乐器后再点一次会补齐另一组最低弦定位点）

### 6. 右手三个状态的期望位置摆放

除 `Fret_P0~P3` 外，一键初始化还会把右手 Low/End/High 三个状态的**位置记录器**直接摆到吉他上的期望位置。右手各状态的位置完全由 4 个品定位点（确定弦坐标系）+ 2 个右手定位点（确定拨弦基准）计算得到。旋转记录器（`Normal_P*_H_rotation_R`）不参与自动摆放，仍需手动摆姿势后 Set。

**各手指对应的弦**（弦序号 1 = 1弦最高音弦；小于 1 表示越过 1弦后按相同弦间距外推的位置）：

| 状态 | p（拇指/匹克） | i | m | a | ch | 含义 |
| --- | --- | --- | --- | --- | --- | --- |
| Low | 最低弦 | 最低弦-1 | 最低弦-2 | 最低弦-3 | 最低弦-4 | 拇指在低音弦的手位（吉他拇指在6弦，贝斯在4弦） |
| High | 3弦 | 1弦 | 1弦 | 1弦 | 2弦 | 高音弦手位（i/m/a 捏在1弦） |
| End | 越过1弦 | 越过1弦 | 越过1弦 | 越过1弦 | 越过1弦 | 扫弦结束，整只手越过1弦 |

电吉他只有匹克（拇指）一个拨弦点：Low 在最低弦、High 在 1弦、End 越过 1弦；`*_h`/`*_hp`（手掌/手臂轴心）同样摆放，电吉他不存在的手指记录器自动跳过。

**几何计算**（实现见 `right_hand_state_locations`）：

- 第 n 弦的拨弦基准点由 `S1_Right` 与 `S6_Right`（贝斯为 `S4_Right`）沿弦方向线性插值：`t = (n - 1) / (最低弦 - 1)`；`n` 越过 1弦（End 状态，n = 0）时按相同间距向外推（实现见 `string_pick_point`）
- 由品定位点构建弦坐标系：`u` 沿弦指向琴桥、`v` 从1弦指向最低弦、`n = v × u` 为弦平面法线（朝上）
- 手指触弦点落在拨弦基准点上；落在同一根弦上的多根手指沿弦方向按 `FINGER_SPREAD = 0.008` 依次错开
- 手掌 `H_R` 在指尖质心后方（朝琴头）`RIGHT_HAND_BACK = 0.18`、高于弦平面 `RIGHT_HAND_UP = 0.04`；手臂 IK 轴心 `HP_R` 再向后 `RIGHT_ARM_BACK = 0.08`、抬高 `RIGHT_ARM_UP = 0.24`；拇指轴心 `TP_R` 在拇指触弦点正上方 `THUMB_PIVOT_UP = 0.14`（单位均为米）

以上偏移均为模块顶部常量，可按角色体型调整；它们只是**默认占位**，最终仍应通过摆姿势 → Set 精修。由于右手位置直接由 `S1_Right`/`S6_Right` 决定，把它们摆准（通常落在音孔上方的拨弦处）是右手自动落位准确的前提。

**与「记录基准状态」的配合**：勾选时，记录每个右手状态前会先由 `move_right_hand_controllers` 把右手控制器摆到该状态的期望位置再 Set——因此运行结束后右手控制器停在 High 状态姿势上，记录器与控制器一致；取消勾选时只摆放记录器，控制器不动。

### 7. 容错与幂等性

- **必需点**为 1弦两端 + 最低弦两端的 4 个品定位点 + 2 个右手定位点共 **6 个**，缺少任何一个都无法完成计算
- 必需点缺失时不摆放 `Fret_P0~P3` 与右手状态记录器，并明确提示缺少哪些物体；一个定位点都没创建时提示先点击「创建吉他定位点」（不会用默认布局的位置去计算，避免摆出错误结果）
- 全流程可重复运行：控制器/记录器由 `setup_all_objects` 复用已有对象，定位点按名字复用
- `GuitarPoints` 集合若被用户从场景断开链接，创建时会自动重新挂回场景，避免定位点不可见

### 8. 左右手基准状态记录

勾选「记录基准状态」（默认勾选）时，一键初始化会把**当前控制器姿态**通过 `transfer_left_hand_state` / `transfer_right_hand_state`（direction='set'）写入全部基准状态记录器：

- **左手**：P0~P4 × Normal/Outer/Inner/Barre 共 20 个组合，跳过 `invalid_combinations` 中的 4 个无效组合（P0+Inner、P2+Inner、P1+Outer、P3+Outer），实际记录 **16 组**。每组写入 H_L、HP_L、T_L、TP_L、I_L、M_L、R_L、P_L 的位置与旋转，以及 H_rotation_L 的旋转
- **右手**：Low、End、High **3 个状态**。每组写入 H_R、HP_R 的位置与旋转、H_rotation_R 的旋转，以及各手指控制器（电吉他只有拇指 T_R；指弹/bass 为 T_R、TP_R、I_R、M_R、R_R、P_R）的位置。**记录每组前会先把右手控制器摆到该状态的期望位置**（见第 6 节），因此即使从未手动摆过姿势，记录到的也是落在吉他上的合理占位姿态

由于记录的是**运行那一刻**的控制器姿态，新角色的推荐完整流程是：

```
创建并摆放定位点 → 一键初始化(创建对象) → 初始化mmd骨骼(绑定手指) → 再点一次一键初始化(记录绑定后的姿态)
```

第一次运行时控制器尚未绑定骨骼，记录的只是占位数据；绑定后再次运行即被有意义的手指姿态覆盖。之后再用面板上的 Set 按钮**精修**需要调整的组合即可，无需从零开始摆每个状态。

## 局限与注意事项

1. **弦序必须标对**：`S1` 必须是最高音弦。标反会导致动画端跨弦插值方向颠倒（高音弦与低音弦互换）
2. **0品/12品不能放反**：两点放反时程序无法检测，`Fret_P0`/`Fret_P1` 会被推到错误一侧
3. 定位点应放在弦中心线上（0品点在弦枕正上方、12品点在12品品格丝正上方），偏离会让所有插值位置产生系统性偏差
4. **右手定位点决定右手全部落位**：`S1_Right`/`S6_Right` 应放在对应弦上右手实际拨弦的位置（指弹吉他约音孔上方）；中间弦的拨弦点按两弦连线线性插值，若两弦右手点高度/前后不一致，中间弦会取中间值，倾斜的手位会被如实还原
5. 一键初始化不包含 MMD 骨骼初始化，因为手指绑定要求先选中骨架；两个步骤的推荐顺序是：先一键初始化（创建控制器），再初始化 mmd 骨骼（绑定手指），最后再运行一次一键初始化记录基准状态
6. **「记录基准状态」重复运行会覆盖**：记录的是运行那一刻的控制器姿态，如果只是调整定位点后更新 `Fret_P0~P3`，请取消勾选，或先导出人物信息备份
7. **右手期望位置是估算值**：由右手定位点加固定常量偏移自动摆放，未考虑角色手型与 rig 的具体比例；且**旋转记录器不自动摆放**。初始化后请用 Load → 摆姿势 → Set 逐状态精修位置与旋转
